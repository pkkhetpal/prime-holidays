# Prime Holidays — Luxury Simplified

A responsive, single-page travel website inspired by the supplied luxury Diwali travel greeting: deep midnight navy, warm gold accents, elegant serif typography and destination-led photography.

## Run locally
No build tools are required. Open `index.html` in a browser, or run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Included
- Responsive navigation and mobile menu
- Destination discovery cards
- Trip search enquiry form
- Custom trip enquiry form
- Luxury editorial sections and responsive layouts

## Before publishing
- Replace `hello@primeholidays.example` in `script.js` with your real enquiry email.
- Replace the sample destination photography with licensed brand imagery if needed.
- Update destination names, copy, package details and social links to match your business.
- Connect the enquiry forms to a booking/CRM backend for production use. The current forms open the visitor's email application.

## Deploy
This static site can be hosted with GitHub Pages, Netlify or Vercel.
